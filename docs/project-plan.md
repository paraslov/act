# ACT Working System — Roadmap

## Цель системы

Создать компактную личную систему, которая помогает:

1. быстро понять, что со мной происходит;
2. выбрать подходящий ACT-навык;
3. совершить действие в сторону ценностей;
4. отслеживать не настроение, а рост психологической гибкости.

Критерий готовности:

> Я могу вспомнить основную систему без конспекта и применить её в реальной ситуации за 30–90 секунд.

## Этап 3. Создать карту состояний

Здесь мы описываем не эмоции сами по себе, а основные способы, которыми я становлюсь психологически негибким.

* [ ] Описать мои типичные проявления **Fusion**
* [ ] Описать мои типичные формы **Experiential Avoidance**
* [ ] Найти ситуации, где включается **Autopilot**
* [ ] Выписать повторяющиеся **Self-stories**
* [ ] Определить признаки **Values Drift**
* [ ] Выписать типичные **Away Moves**
* [ ] Для каждого состояния указать противоположный функциональный ответ

Базовая таблица:

| Состояние      | Как выглядит у меня                          | Нужный процесс   |
| -------------- | -------------------------------------------- | ---------------- |
| Fusion         | Мысль превращается в факт или приказ         | Defusion         |
| Avoidance      | Поведение строится вокруг устранения чувства | Acceptance       |
| Autopilot      | Реагирую до осознанного выбора               | Present Moment   |
| Self-story     | «Я такой человек, поэтому…»                  | Self-as-Context  |
| Values drift   | Теряю из вида важное направление             | Values           |
| Stuck behavior | Избегаю или действую импульсивно             | Committed Action |

Результат этапа: `My ACT States Map`.

## Этап 4. Собрать основной Skill Tree

Не коллекционировать десятки техник. Сначала освоить шесть базовых навыков:

* [ ] **Notice** — замечать мысль, эмоцию, импульс, тело и поведение
* [ ] **Defuse** — видеть мысль как мысль, а не приказ
* [ ] **Accept / Make Room** — оставлять место внутреннему опыту
* [ ] **Anchor / Return** — возвращать внимание и управление поведением
* [ ] **Orient to Values** — определять, что важно в конкретной ситуации
* [ ] **Committed Action** — совершать конкретный Toward Move

Для каждого навыка создать короткую карточку:

```text
Когда применять:
Что именно делать:
1–2 основные техники:
Типичная ошибка:
Как выглядит успешное применение:
```

Ограничение: сначала не больше **двух техник на один навык**.

Результат этапа: `ACT Skill Cards v1`.

## Этап 5. Собрать практические протоколы

### Утренняя настройка — 1 минута

* [ ] Какой внутренний дискомфорт я готов сегодня испытывать?
* [ ] Что особенно важно сегодня?
* [ ] Каким человеком я хочу действовать?
* [ ] Какой один Toward Move я сделаю?

### Когда «зацепило» — 30–90 секунд

* [ ] **Notice:** что сейчас происходит?
* [ ] **Open:** могу ли я оставить этому немного места?
* [ ] **Defuse:** какую историю рассказывает мозг?
* [ ] **Orient:** что здесь важно?
* [ ] **Choose:** Away или Toward?
* [ ] **Act:** какой минимальный следующий шаг?

### Вечерний review — 2–3 минуты

* [ ] Где сегодня меня зацепило?
* [ ] Какой Away Move я сделал?
* [ ] Где удалось проявить гибкость?
* [ ] Какой Toward Move я хочу попробовать в следующий раз?

### Еженедельный review — 10–15 минут

* [ ] Какие Hooks повторяются?
* [ ] Какие формы избегания дают краткое облегчение, но имеют долгосрочную цену?
* [ ] Какой навык оказался слабым?
* [ ] Какую одну технику тренировать следующую неделю?
* [ ] Какое действие по ценностям запланировать?

Результат этапа: `Daily and Weekly ACT Protocols`.

## Этап 6. Определить ценности

Ценности нужны не как абстрактный список красивых слов, а как качества поведения.

* [ ] Выбрать 4–6 важных областей жизни
* [ ] Для каждой ответить: «Каким человеком я хочу здесь быть?»
* [ ] Отличить ценности от целей и социальных `shoulds`
* [ ] Для каждой ценности определить наблюдаемые Toward Moves
* [ ] Найти характерные Away Moves
* [ ] Выбрать 1–2 приоритетных направления на ближайший месяц

Шаблон:

| Область | Ценность — качество поведения  | Toward Move                    | Away Move            |
| ------- | ------------------------------ | ------------------------------ | -------------------- |
| Семья   | Быть внимательным и терпеливым | Дослушать перед ответом        | Раздражённо оборвать |
| Работа  | Быть ясным и справедливым      | Дать конкретную обратную связь | Избегать разговора   |

Результат этапа: `Personal Values Map`.

## Этап 7. Настроить измерение прогресса

Главный критерий:

> Смог ли я при наличии дискомфорта совершить осознанный Toward Move?

После значимой ситуации оценивать по `0–2`:

* [ ] Я заметил внутреннюю реакцию
* [ ] Я не потратил все силы на борьбу с ней
* [ ] Я создал паузу перед действием
* [ ] Я вспомнил, что важно
* [ ] Я сделал соответствующее действие

Не использовать этот балл для самокритики. Он нужен для обнаружения закономерностей.

Дополнительно:

* [ ] Провести стартовое измерение Psy-Flex
* [ ] Повторять его раз в 2–4 недели
* [ ] При необходимости позже использовать MPFI для подробного профиля
* [ ] Не измерять ежедневно тревогу или настроение как главный результат ACT

Результат этапа: `ACT Progress Tracker`.
